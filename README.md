# Chinese-homework
中文在线作业练习系统

AI生成作业支持上传本地PPTX、DOCX、PDF、TXT、MD课件（单文件20MB；PDF最多200页）。在教师工具中选择所属题库等级，上传课件并核对提取文字，然后选择题型和题数生成。最多采用7000字，超出时界面会提示；可以编辑内容或分批上传。移除课件后恢复原题库出题。扫描PDF及纯图片课件需先OCR为文字；旧版PPT/DOC请先另存为PPTX/DOCX。文件在浏览器本地解析，仅在点击生成时将核对后的文字发送给现有AI服务。

PDF解析使用随项目部署的PDF.js 4.10.38（Apache-2.0），许可见 `vendor/pdfjs-LICENSE`；字体许可保留在 `vendor/pdfjs/standard_fonts/`。Office文件使用浏览器原生解压功能，需支持 `DecompressionStream('deflate-raw')` 的现代浏览器。

课件作业现在自动过滤英文、越南语、拼音及数字编号，仅保留中文及中文标点。出题先从课件中文提取词语和句子，按目标分批生成，避免反复选择相同词语。中文内容不足会提示减少题数或补充课件；某题型连续失败时保留结果并继续其他题型。

AI作业规则：拼音干扰项优先使用z/zh、s/sh、c/ch等模糊音；填空和排序题使用不同情境，重复或高度相似的完整句子会被过滤并重新补题。翻译题的越南语题干为10—15个词（按空格分隔计数），超出范围会重新生成；中文参考译文与题干对应。

填空题按填回正确答案后的完整句子去重；同句换挖空位置、选项或标点会被过滤并补题，同批次和跨批次均检查。课件填空题仅提取词语作为目标，要求AI编写新情境完整句，不再用课件标题或课堂提问直接挖空补齐。Word导出前再次校验重复题。

### 教材式课件与 PPT 下载

教师工具 → **AI 设计课件**：当前开放 HSK1–2 前三个预制主题，按“目标 → 热身 → 课文／生词 → 语法讲解 → 练习 → 交际／文化 → 课后任务”展示。第03课《我是越南人》使用新版初级对话，不再按300字凑长。预览、学生讲义 Word 与可编辑 PPT 共用课程数据；所有页面含 `Tiếng Trung Cô Nga -Zalo:0966795638` 页眉页脚。学生讲义不包含参考答案；网页填空答案默认隐藏，教师可切换显示。此入口仍为预制课件，未接入任意主题的在线 AI 生成。

- **下载学生讲义 Word**：A4纵向，包含三语课文、词表和练习，可在 Word/WPS 修改、打印。
- **下载PPT 课件**：16:9横向，拼音／汉字／越南语文本可编辑；预览窗口中也可下载。
- 其他题库或未开放主题会禁用预览和下载，不会导出错误主题。
- 课件数据位于 `courseware/data/`；新版支持目标、热身、语法、理解题、综合练习、交际、文化及作业模块。`courseware-core.mjs` 负责验证和展示分页，Word保持纵向连续排版。

验证：`node --test tests/courseware.test.mjs tests/homework.test.mjs tests/roles-and-exercises.test.mjs tests/release-refresh.test.mjs`。浏览器集成验证在本地静态服务器启动后运行 `node tests/courseware-browser.cjs`（需要 Playwright 和 Chromium；可设置 `COURSEWARE_BASE_URL`、`CHROMIUM_PATH`）。
