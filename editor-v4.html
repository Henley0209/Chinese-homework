文字内容

新版已删除原英文副标题，并放大网站名称。主页标题、欢迎语和页脚文字可清空；清空后立即隐藏对应内容。

网址留空时隐藏链接；填写后显示在名称下方，点击会在新标签页打开。

背景照片与排版

选择课堂照片，自动压缩并保持比例；填满区域时边缘可能裁切，不会拉伸变形。图片将包含在下载的配置中，无需单独上传。

0%隐藏照片，100%完整显示照片；调低可让照片更淡。

照片太暗时调高白色遮罩；想看清照片细节时调低。仅影响照片，不改变文字透明度。

如何让所有学生看到修改？
  1. 点击“下载配置文件”，得到 site-config.json。
  2. 打开下面的GitHub仓库，选择 Add file → Upload files。
  3. 上传该文件到仓库首页，替换同名文件，点击 Commit changes。
  4. 等待网站部署完成，再刷新主页。
