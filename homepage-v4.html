下载题目格式示例 ↓

如何同步给所有学生？
  1. 点击“下载题库发布文件”，得到 exercise-catalog.json。
  2. 打开GitHub仓库，选择 Add file → Upload files。
  3. 上传并替换仓库首页的 exercise-catalog.json，点击 Commit changes。
  4. 部署完成后刷新网页，练习列表会自动匹配更新。
